# IEDSyncTogether v0.4.0 placement synchronization

## Goal

Synchronize the final IED placement of a displayed/favorited item, not only its FormID.

v0.3.3 proved that remote favorites are correctly captured, transported and rendered once IED's `disable_npc_slots` setting is enabled. The remaining mismatch was spatial: Kahel's spear was restored on the sword hip slot and the shield on an incorrect node instead of matching Player1's Node Override placement.

## Capture model

IED's public Papyrus API exposes setters for Custom Item transforms but no getters for ordinary slot transforms. v0.4.0 therefore reads the already-evaluated PlayerCharacter scene graph.

For each non-empty IED slot:

1. `IED.GetSlottedForm` supplies the authoritative displayed form.
2. IEDSyncTogether finds the corresponding live gear node (`WeaponSword`, `ShieldBack`, etc.).
3. Starting with that gear node's local transform, it walks upward through all `MOV ...` and `CME ...` helper nodes.
4. Each helper transform is composed using Skyrim's hierarchy rule `parent * child`.
5. The walk stops at the first stable non-IED skeleton node.
6. The stable anchor name plus the complete composed translation, rotation and scale are serialized with the FormIdentity.

This captures both the selected Node Override placement and offsets stored on intermediate IED/XPMSSE helper nodes. It does not access private IED controller memory.

## Remote restitution

For each synchronized form, the remote client:

1. creates an IED Custom Item with `abIsInventoryForm=false`;
2. uses the captured stable skeleton anchor as its target node;
3. applies the composed translation with `SetItemPositionActor`;
4. applies the composed rotation with `SetItemRotationActor`;
5. applies the composed scale with `SetItemScaleActor`;
6. evaluates the proxy.

If placement capture is unavailable for a slot, the renderer falls back to the canonical gear node and still restores the item.

## Test focus

With `disable_npc_slots=true` on both clients:

- Kahel's Iron Hunter's Spear should be on the same back placement for Player2 as it is locally for Player1.
- Kahel's Iron Shield should be stowed on the same placement instead of appearing in hand.
- The Springsteel Bow should retain its effective IED placement.

Compare owner logs containing `IED placement chain` / `IED placement captured` with observer logs containing `IED placement applied`.

No ActorBlock probe or private IED runtime hook is used.
